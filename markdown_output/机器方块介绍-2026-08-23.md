日期：2026-08-23

## 一、动力角磨床（Power Angle Grinder）

**定位**：应力驱动的多功能加工机器，靠机械动力运转，仿 Create 动力锯。

### 摆放与接线
- **水平朝向**：放置时面对玩家，仅水平 4 向（FACING）。
- **传动轴接入**：传动轴从 **FACING 前方**（齿轮箱纹理背板侧）接入，水平旋转轴沿机器朝向。
- **盖板位置**：盖板在 FACING **对面一侧**，开盖时朝那一侧翻起；那一格被方块阻挡时无法开盖（提示"空间不足"）。

### 使用流程
1. **开盖**：用扳手右键切换开盖状态（有 WRENCH_ROTATE 音效）。
2. **安装角磨轮**：开盖后手持角磨轮右键安装（消耗 1 个轮）；空手右键可取出轮子。
3. **投入原料**：物品从**顶部丢入**、或从**侧面漏斗/传送带输入**、或开盖后手持放入。
4. **合盖加工**：合盖且有应力（转速达标）时开始加工，碎屑粒子沿轮子切向飞溅。
5. **取出成品**：空手右键分批取——第一次取成品区，成品区空了再取原料；有漏斗时由漏斗抽取。

### 角磨轮等级（决定能加工什么）
- **1 级轮**：铁 / 金 / 黄铜 / 锌 → 基础角磨（GRINDING）
- **2 级轮**：翡翠 / 钻石 / 黄玉 → + 粉碎、研磨（CRUSHING / MILLING）
- **3 级轮**：蓝宝石 / 星辉石 / 下界合金 → + 装备/武器拆解（DISMANTLING）
- 等级判定走 tag（`grinding_wheels/tier_N`），拓展模组把轮子加进 tag 即可升级。

### 转速与耗时（默认配置，可在 `createoreexpansion-common.toml` 的 `grinding` 段调整）
| 轮子等级 | 最低工作转速 | 最低转速下基础耗时 |
|---|---|---|
| 1 级（铁/金/黄铜/锌） | ≥ 64 RPM | 10 秒 |
| 2 级（翡翠/钻石/黄玉） | ≥ 96 RPM | 5 秒 |
| 3 级（蓝宝石/星辉石/下界合金） | ≥ 128 RPM | 3 秒 |

- 加工耗时随转速线性缩短：最低转速 → 该级基础耗时，满转速（Create 上限，默认 256 RPM）→ 1 秒。
- 低于最低转速不加工（护目镜提示"转速不足"）。

### 角磨轮特殊效果（护目镜可见）
| 轮子 | 效果 |
|---|---|
| 金 | 25% 概率额外产出一份结果 |
| 黄铜 | 加工时间减少 25% |
| 锌 | 加工时间减少 15% |
| 翡翠 | 15% 概率产物翻倍 |
| 钻石 | 加工时间减少 15% |
| 黄玉 | 每种产物数量 +1 |
| 蓝宝石 | 35% 概率额外产出一份结果 |
| 星辉石 | 加工时间减少 30% |
| 下界合金 | 每种产物数量 +2 |

### 护目镜信息
- 未装轮：红色"未安装角磨轮！"
- 已装轮：轮子名、特殊效果、所需转速（≥ X RPM）、当前加工耗时
- 悬停提示（非护目镜）：当前支持的加工类型列表

### 细节
- 合盖才能加工；开盖时机器暂停。
- 成品区 32 格，可堆叠；漏斗可从底部抽取输出、顶部输入。
- 槽满时多余成品掉落到机器上方（不静默丢失）。
- 无匹配配方的物品按正常节奏消耗（有粒子、不瞬间消失）。
- 支持 Create 序列装配（角磨步骤）。

## 二、翡翠应力充能器（Jade Create Charger）

**定位**：应力驱动的能量波发射器，为能量工具/凝能佩充能、转化普通物品、可伤害生物。

### 摆放与接线
- **应力驱动**：需接入机械动力，转速越高档位越高。
- **发射方向**：沿 FACING 方向发射能量波，发射头有蓄力收缩/弹出动画。

### 充能档位（按转速自动切换，护目镜可见）
| 档位 | 转速条件（上限=Create maxRotationSpeed，默认 256） | 颜色 | 波速 | 伤害 | 充能点数 |
|---|---|---|---|---|---|
| 低充能 | 1 ~ ½ 上限（含 ½） | 黄 | 2 格/秒 | 4 | +100 |
| 高充能 | ½ 上限（不含）~ 上限（不含） | 绿 | 4 格/秒 | 6 | +500 |
| 伽马 | ≥ 上限 | 蓝 | 6 格/秒 | 10 | +1000 |

- 档位按 Create 配置上限等比划分，上限可调时自动跟随，不硬编码。
- 边界细节（读源码确认）：`speed ≤ ½上限` → 低；`½上限 < speed < 上限` → 高；`speed ≥ 上限` → 伽马。

### 发射节奏
- 蓄力间隔：转速 1 → 10 秒一发，256 → 1 秒一发，线性插值；更快保持 1 秒。
- 蓄力进度护目镜可见（能量条，填充色=当前档位颜色）。

### 能量波行为（飞行途中）
1. **命中生物**：造成对应伤害（创造玩家免疫），波消散。
2. **命中掉落物**：
   - 能量工具/凝能佩 → 直接充能（按档位 +100/500/1000，封顶不消耗物品）；
   - 普通物品 → 按充能配方消耗 1 个并产出结果（落在原位置）。
3. **命中置物台/工作台（有物品槽方块）**：尝试给槽内物品充能/转化；无论是否匹配，波都**在此消散**（不穿过置物台）。
4. **命中强化避雷针（仅伽马波）**：充能进度 +1（攒满获得手动引雷），波消散。
5. **撞墙**：消散（对应颜色粒子绽放 + 紫水晶共鸣音效）。

### 护目镜信息
- 标题"翡翠应力充能器"、当前档位（RPM 区间）、蓄力进度能量条。

## 三、强化避雷针（Reinforced Lightning Rod）

**定位**：继承原版避雷针全部行为（雨天自动引雷、被击中、露天判定、三叉戟交互），叠加伽马能量波充能系统。

### 原版行为（完整继承）
- **雷暴自动引雷**：通过 POI 映射，雷暴天闪电会被吸引到本方块（与其他避雷针行为一致）。
- **被自然闪电击中**：维持原版 POWERED 红石脉冲等行为。
- **露天判定**：非露天（上方有遮挡）时不会引雷/无法释放。
- **三叉戟引雷**：沿用原版交互。

### 伽马能量波充能（新增玩法）
1. **充能**：翡翠充能器发射的**伽马波**（蓝、3 档）命中时，充能进度 +1（金色电光粒子反馈）。
2. **攒满就绪**：进度满 **10 格**后停止充能，出现金色"引雷充能就绪！右键释放闪电"提示。
3. **手动释放**：右键方块，在避雷针上方生成一道**纯视觉闪电**（不引燃、不生成骷髅陷阱马）。
4. **冷却**：释放后进入 8 秒冷却，期间无法再次释放。
5. **重新充能**：释放后进度归零，重新开始攒。

### 护目镜信息
- 标题"强化避雷针"、金色竖线充能进度条、满格时金色就绪提示。

### 细节
- 充能进度实时同步到客户端（戴护目镜可见逐格增长）。
- 存档/退出重进：进度、就绪状态、冷却均持久化保存。
- 方块被破坏掉落时物品**不携带**充能状态。
