# 二、能量波核心机制

- **三档等级**：低（2 格/秒、4 伤）/ 高（4 格/秒、6 伤）/ 伽马（6 格/秒、10 伤），颜色随等级渐变（平滑过渡）
- **波实体**：寿命/距离双上限自动消散（防卡顿）；波波碰撞相互湮灭 + 范围能量爆炸（不破坏地形）
- **波加工**：命中掉落物/置物台/工作台按充能配方转化（含能量工具充能）；命中生物造成伤害
- **入口判定**：面板中心 **4×4 区域**才算有效进入（斜射/偏移射擦边 → 撞墙消散），容错度明确
- **渲染**：齿轮随应力旋转（转速达标转、不足静止）、侧面指示灯（面板开 + 转速达标才亮，自发光）、机座模型按面板开闭切换

# 三、Sable 物理结构适配（大更新 ⭐）

能量波与**物理化结构**（飞机/船/载具，sub-levels）全面打通：

- **结构上的充能器可正常发射**：波出生在真实世界（经位姿矩阵换算），方向随结构旋转**任意角度**
- **结构上的波闸/差波器正常处理**：波撞结构（本地坐标系判定），升/降级、加减速、分裂、反弹全支持；分裂子波坐标转回世界
- **坐标系统**：世界 ↔ 结构本地 通过 Sable 位姿矩阵（Pose）勾连，含 plot 中心偏移处理
- **依赖**：仅需 Sable（Aeronautics 1.3.x 起不再需要 Valkyrien Skies）；未装时模组完全正常（可选集成）
