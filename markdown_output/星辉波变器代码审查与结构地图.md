## 4. 需要你拍板的口径问题（9 条）

1. **分裂时载荷归属**：本轮我按"**按开口数均摊**（含 chainLeft；引雷次数整份给第 0 个子波）+ 母波不再释放"实现。如果你更想要"只给第一个子波"或"子波不继承载荷"，说一声。
2. **引雷粒度**：本轮已改成"**一次命中最多引一道雷**"。若你要"打中每个掉落物都能引"，需要回退这条并接受额度被一次命中烧光。
3. **护目镜"引雷次数"**：现在报"半径内已蓄满避雷针台数"，实际一次穿波只拿 1。要①改文案（"已蓄满 N 台 · 每发波抽 1 次"）还是②改成"一次抽干半径内所有满针"？
4. **"读到储能设备 N 台"**按"存在即计数"（现）还是"可抽取才计数"？
5. **两台变器相邻**：现在会互相算作"1 台动能机"（机器数/应力乘子互相抬一档）。有意还是排除同类？
6. **余料兜底位置**：`DROP_AT_DISSIPATION` 与"就近尽力而为"现在用的是**波当前位置** 1 格邻域（`nearestFluidHandlerFill`），而物品支路退"来源方块"。要不要统一成"最近加工过的方块周围、变器读取半径内"（并加排除口径）？
7. **漏斗/溜槽**是否算"可保存容器"？现在会被当普通容器收下余料，而它会立刻把东西转给下游（常常正是工作盆）。
8. **序列装配/随机产物的两处口径**：步骤配方的第 2..n 个产物要不要照 Create `rollResults` 滚出？过滤器闸门要不要改测"整个结果池"？
9. **存档里的波**：载荷本就不落盘。要"补写 chain/recipeTypes/waveOrigin 让读档波继续可用"，还是"读档直接消散"（更干净）？
