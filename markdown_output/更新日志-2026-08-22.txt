Create Ore Expansion 更新日志
日期：2026-08-21

一、新增机器：翡翠应力充能器（jade_create_charger）
1. 六向应力机器（可水平/竖直放置，优先对准相邻传动轴）
   - 按转速分三档充能态：低（≤½ 上限转速）/ 高（½~上限转速）/ 伽马（≥上限转速）
   - 上限转速读取 Create 配置 maxRotationSpeed（默认 256 RPM，可调，不硬编码）
   - 蓄满自动发射对应等级能量波（音效：音符盒钟声），发射头带蓄力收缩/弹出动画
2. 能量波命中效果：
   - 生物：造成伤害（低 4 / 高 6 / 伽马 10）
   - 掉落物/置物台物品：能量工具充能（100/500/1000 点）或按配方转化（命中音效：紫水晶共鸣）
   - 粒子用原版染色粒子（DustParticleOptions），零自定义粒子注册、零卡顿
3. 护目镜提示：充能态 + 蓄力进度能量条（复用 BarTooltipRender，颜色随等级）

二、充能配方体系统一（关键架构改进，方便第三方适配）
1. 配方类型由三个（charging / charging_high / charging_gamma）合并为**一个** createoreexpansion:charging
2. 等级改为配方自带字段 level（1=低、2=高、3=伽马）：
   { "type": "createoreexpansion:charging", "level": 2, "ingredients": [...], "results": [...] }
3. 机器按等级匹配：能量波等级 ≥ 配方 level 即加工（取等级最高者），等级不够跳过
4. 第三方/整合包适配只需写一条带 level 字段的配方 JSON，无需任何 Java 代码

三、JEI 展示
1. 低/高/伽马三个分类合并为一个「充能加工」分类，配方卡片上以等级徽章区分（低=黄、高=绿、伽马=蓝）
2. 分类图标去掉右下角翡翠锭叠加（仅充能器图标）
3. 传动轴改为 4px 短轴（替代 Create 全尺寸 16px 轴）防止穿模
   - 修正位置：blockstate 旋转绕方块中心，接口落在 y=16，轴模型定位于 y 12~16（机身下方）
4. 工具充能配方（31 物品 × 3 等级 = 93 条）统一生成到 tool_charge/ 一个文件夹，
   等级由 level 字段区分，文件名后缀 _low/_high/_gamma 仅保证 id 唯一

四、光照规则修复（仿 Create 机器）
1. 动力角磨床、翡翠应力充能器不再阻挡光照：
   - 天空光可无衰减穿透（propagatesSkylightDown = true）
   - 自身面不做环境光遮蔽变暗（getShadeBrightness = 1.0）
   - 修复：坑里放创造马达、上方放充能器时马达亮度骤降的问题
2. 逻辑写入充能器抽象基类 AbstractCreateChargerBlock，雷鸣充能器自动继承

五、其他
1. 充能器/角磨床注册保持 noOcclusion + isRedstoneConductor(false)
2. 翻译统一维护于 ChineseLangProvider / EnglishLangProvider
