## 3. 无论谁接手，都该先记住的六条判据

1. **依赖方向是唯一分层判据**：谁需要它，它就必须住在谁那里。
2. **关卡必须认识依赖方向**（否则会把合法的 `cews → coe` 误报成缺陷 —— 本工程已经修过一次这个错）。
3. **弄坏必须变红**：改了关卡就要做扰动实测（含「把合法方向挪走仍应 PASS」这一侧）。
4. **新关卡/新判据的第一次输出不能当结论**：先问「这个数字是**旧判据**还是**新判据**算出来的」。
5. **`porcelain = 0` 是交回条件**；提交一律 `git commit -- <路径>`（**绝不 `git add -A`**）。
6. **四条不可动**：注册命名空间 / 注册 id / 语言键 / 数据包路径；**贴图一个字都不改、也不自己画**。
