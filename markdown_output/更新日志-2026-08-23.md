# 战利品 & 世界生成（按规格实现）

## 通用约束（已遵守）

1. 所有战利品注入均用**新增独立 pool**（`neoforge:add_table` 注入独立子表），不修改原版战利品池。
2. 猪灵对蓝宝石与金同等喜好（`#piglin_loved` tag 追加蓝宝石锭/块）；蓝宝石装备未实现（蓝宝石锄仅彩蛋）。
3. 结构彩蛋全部依靠自定义 StructureProcessor 实现，**不覆盖原版结构模板 nbt**。

## 四、星辉石锭（末地）

1. 末影船鞘翅房：两个箱子**有且仅有一个**产出 2-4 星辉石锭（mixin 改专属子表，不双刷）
2. 末地城普通塔楼宝箱：`weight=7`，数量 1-3
3. 矿石生成：既有（用户已实现，未改动）
4. 末影船彩蛋：50% 概率将龙首（`dragon_wall_head`）后方船体方块替换为星辉石块（`EndShipStellarstoneProcessor`，隐藏建筑彩蛋）

## 实现要点

- 战利品注入：NeoForge `AddTableLootModifier`（`neoforge:add_table`）+ `LootTableIdCondition` 限定目标表，16 个 modifier 注册于 `data/neoforge/loot_modifiers/global_loot_modifiers.json`
- 猪灵喜爱/激怒：`data/minecraft/tags` 追加（`replace:false`，不覆盖原版）
- 结构处理器注册：`RegisterEvent` 注册 `StructureProcessorType`（`AllStructureProcessors`）
- 堡垒挂载：覆盖 `bastion/treasure/bases/centers.json` 的 `processors` 引用为 `createoreexpansion:treasure_rooms_sapphire`（含原版 `treasure_rooms` 规则 + 自定义处理器），不覆盖任何 nbt 模板
- 末地船挂载：mixin `TemplateStructurePiece`（`postProcess` HEAD 追加处理器 + RETURN 改船箱子专属表），不覆盖任何 nbt 模板

## 测试后调整（二轮）

17. **末地船箱子空荡荡（只有星辉石锭）**
    - 原因：mixin 把船箱子整体替换成只有星辉石的子表，覆盖了原版鞘翅房战利品
    - 修复：`end_ship_stellarstone` 子表改为「原版 `end_city_treasure` 全部内容 + 星辉石 2-4 保底 pool」，船箱子 = 原版战利品 + 星辉石
18. **矿石刷新频率偏高（蓝宝石/星辉石矿脉 size 5 过大）**
    - 修复：`nether_sapphire_ore` 与 `end_stellarstone_ore` 的 `size` 5 → 3（蓝宝石对标远古残骸 size 2；星辉石收回"适度上调"）
    - 翡翠（size 10）/黄玉（size 8）维持不变（用户认可）
