# ⚔️ 机械动力：矿物扩展 —— 技能系统更新公告

> 本次更新：全系 4 种矿物工具（翡翠/黄玉/蓝宝石/星辉石）技能体系重构、
> 新增双技能按键、一技能多等级机制、多项体验修复。

---

## 🎯 更新总览

- **4 种矿物工具**（翡翠→黄玉→蓝宝石→星辉石）逐级增强，每把工具绑定对应技能等级
- **新增技能释放键 2 / 键 3**（默认 R / G，可自定义）
- **剑/铲双技能系统**：一把武器可绑两个技能，按不同键分别触发
- **一技能多等级机制**：`addSkills(技能, 等级)` 等级同时决定显示与实际数值
- **修复**：不按技能键不再误弹提示、大树不会一次砍光、方块放置不再消失、甜菜根不再无限产出

## 🔧 其他改进

1. **不按技能键不再误弹提示**：只有按住技能键释放技能后才显示剩余能量
2. **技能名显示优化**：按住 Alt 查看技能，等级用罗马数字（I/II/III）清晰展示
3. **渲染框颜色可自定义**：支持十六进制 / RGB 自定义轮廓颜色
4. **数值集中管理**：所有技能数值统一在配置类，一技能多等级，便于后续平衡调整
5. **修复**：方块放置后消失、甜菜根无限产出、翡翠斧误全砍大树

---

## 📌 使用提示

- 释放技能 = **按住对应技能键 + 对应操作**（左键挖方块 / 右键 / 攻击生物）
- 剑/铲的双技能可分别用键一（左 Shift）/ 键二（R）触发，冷却独立互不影响
- 所有技能键均可在 **按键设置** 中自定义（技能释放 / 技能释放 2 / 技能释放 3）
- 创造模式下技能无冷却
