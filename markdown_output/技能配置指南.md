# 采掘作战技艺 —— 技能配置指南（示例）

> 本文档说明如何修改各技能的数值（冷却/范围/概率/buff），
> 以及如何在 `AllItems.java` 中定义新工具与轮廓颜色。

---

## 一、技能总览（6 个技能，等级 1~5）

| 技能 | 枚举 SkillType | 工具类型 | 技能类（数值所在） |
|---|---|---|---|
| 伐树 | `FELL_TREE` | 斧 | `skill/impl/FellTreeSkill.java` |
| 开岩 | `BREAK_ROCK` | 镐 | `skill/impl/BreakRockSkill.java` |
| 引渠 | `CHANNEL_DIG` | 铲 | `skill/impl/ChannelDigSkill.java` |
| 平场 | `FLATTEN_FIELD` | 铲 | `skill/impl/FlattenFieldSkill.java` |
| 剥取 | `HARVEST_EXTRA` | 剑 | `skill/impl/HarvestExtraSkill.java` |
| 夺取 | `SNATCH_EFFECT` | 剑 | `skill/impl/SnatchEffectSkill.java` |

## 二、修改技能数值（冷却 / 范围 / 概率 / buff）

所有数值都在各技能类**顶部常量区**，改数组即可（顺序 = Lv1~Lv5）。

### 1. 伐树 `FellTreeSkill.java`

```java
private static final int[] COOLDOWN_TICKS = {40, 60, 80, 100, 160};   // 各等级冷却 tick（20tick=1s）
private static final int[] SEARCH_RANGE = {8, 8, 12, 16, 0};          // 搜索半径（0=忽略）
private static final int[] MAX_BLOCKS = {100, 200, 400, 800, 0};      // 最大方块数（0=无限）
private static final boolean LV1_LOG_ONLY = true;                     // Lv1 是否只砍树干
```

> Lv5 自动启用"无限制"（`SEARCH_RANGE=0` 时用 64 格近似无限）。
> 改法示例：想让 Lv3 范围更大 → 把第 3 个值 12 改成 16。

### 2. 开岩 `BreakRockSkill.java`

```java
private static final int[] COOLDOWN_TICKS = {30, 50, 70, 90, 140};
private static final int[][] RANGE = {  // {宽, 高, 深}
        {1, 3, 1},  // Lv1: 1×3
        {3, 3, 1},  // Lv2: 3×3
        {3, 5, 1},  // Lv3: 3×5
        {5, 5, 1},  // Lv4: 5×5
        {7, 7, 1},  // Lv5: 7×7
};
```

### 3. 引渠 `ChannelDigSkill.java`

```java
private static final int[] COOLDOWN_TICKS = {40, 60, 80, 100, 140};
private static final int[] DIG_LENGTH = {4, 6, 8, 10, 12};  // 向前挖掘长度（格）
```

### 4. 平场 `FlattenFieldSkill.java`

```java
private static final int[] COOLDOWN_TICKS = {80, 100, 120, 140, 200};
private static final int[] RADIUS = {2, 3, 4, 5, 6};  // 半径，边长 = 2*r + 1（Lv1=5×5 ... Lv5=13×13）
```

### 5. 剥取 `HarvestExtraSkill.java`

```java
private static final int COOLDOWN_TICKS = 20;          // 冷却统一 1 秒
private static final float BASE_CHANCE = 0.60F;        // Lv1 基准概率（改这里）
private static final float MAX_CHANCE = 0.90F;         // Lv5 固定概率（改这里）
// Lv2~Lv4 自动在 BASE_CHANCE 与 MAX_CHANCE 之间线性插值
```

### 6. 夺取 `SnatchEffectSkill.java`

```java
private static final int[] COOLDOWN_TICKS = {100, 110, 120, 140, 180};
private static final float[] ARMOR_DROP_CHANCE = {0.0F, 0.0F, 0.75F, 0.90F, 1.0F}; // 装备掉落概率
private static final int[] ABSORPTION_AMPLIFIER = {1, 2, 2, 3, 4};   // 伤害吸收等级（0=吸收I）
private static final int[] ABSORPTION_DURATION_TICKS = {3*20, 5*20, 7*20, 7*20, 7*20}; // buff 时长 tick
```

## 四、在 AllItems.java 定义新工具 + 颜色

### 1. 定义技能发光颜色

颜色在 `client/tool/SkillOutlineColors.java` 集中管理，**支持三种定义方式**：

```java
// 方式一：十六进制（推荐，直观）
SkillOutlineColors.SkillColor.fromHex(0x4CAF50)      // 或 "#4CAF50" 字符串

// 方式二：0~255 RGB
SkillOutlineColors.SkillColor.of(76, 175, 80)

// 方式三：直接浮点 0~1
new SkillOutlineColors.SkillColor(0.3F, 0.69F, 0.31F)
```

想加新矿物颜色，在 `SkillOutlineColors.java` 常量区加一行：

```java
/** 红宝石红 */
public static final SkillColor RUBY_RED = SkillColor.fromHex(0xE0115F);
```

### 2. 定义新工具（完整示例：自定义宝石剑，剥取 Lv2，红色轮廓）

> ⚠️ 示例用到 `AllTiers.RUBY`，当前 `AllTiers` 只有 JADE/TOPAZ/SAPPHIRE。
> 使用前需先在 `common/AllTiers.java` 添加对应材料等级（或用已有 `AllTiers.JADE` 代替）。

```java
public static final ItemEntry<SwordItem> RUBY_SWORD = CreateOreExpansion.REGISTRATE
        .item("ruby_sword", p -> new SwordItem(AllTiers.JADE, p))   // 未定义 RUBY 时先用 JADE
        .model((ctx, provider) -> provider.handheld(ctx::get))
        .properties(p -> p.attributes(SwordItem.createAttributes(AllTiers.JADE, 4, -2.4F)))
        .tag(ItemTags.SWORDS)
        .transform(skillItem())
        .addEnergy()
        .defaultEnergy(600)
        .maxEnergy(600)
        .color(ToolEnergyColorConfig.DEFAULT)
        .build()
        .skill(new SkillInstance(SkillType.HARVEST_EXTRA, 2))   // ← 绑定技能 + 等级
        .skillColor(SkillOutlineColors.RUBY_RED)                 // ← 自定义轮廓颜色
        .build()
        .register();
```

### 3. 修改现有工具颜色

翡翠系已用 `SkillOutlineColors.JADE_GREEN`，想改色只需换常量：

```java
// 翡翠镐：把默认绿改成自定义青色
.skillColor(SkillOutlineColors.SkillColor.fromHex(0x00BFFF))  // 深天蓝
```

## 五、技能释放

- 按住**技能释放键（默认左 Shift）** + 右键方块 → 挖掘类技能
- 按住技能释放键 + 攻击生物 → 剑类技能
- 能量不足或冷却中 → 不释放

---

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 改了数值不生效 | 改的是技能类，需重新编译 + 重启游戏 |
| 颜色没变化 | 改的是 `SkillOutlineColors` 或 AllItems 的 `skillColor`，需重编译 |
| 想加全新技能 | ① 新建 impl 类继承 `MiningCombatSkill`；② 在 `SkillType` 枚举注册；③ AllItems 绑定 |
