## 0. 准备

- 用**带技能装备的老存档**测试更佳（同时验证存档兼容）。
- 拿到带技能的工具/武器（翡翠 / 黄玉 / 蓝宝石 三档；弓为翠玉之弓）。
- 技能键：**键一 / 键二 / 键三**（默认左 Shift / R / G 之类，见游戏内按键设置）。
- 观察三件事：**效果是否出现**、**能量是否被扣**、**是否进入冷却**。

## 1. 挖掘族（EXCAVATION）—— 触发点：破坏方块时

| 工具 | 技能 | 期望现象 |
|---|---|---|
| 斧（翡翠/黄玉/蓝宝石） | `fell` 伐树 | 砍一根原木 → 整棵树的原木（连叶）成片掉落 |
| 镐 | `shatter` 开岩 | 挖一格石头 → 周围一片石头同时碎裂 |
| 铲 | `channel` 引渠 | 挖一格土/沙 → 沿一条线成渠 |
| 铲 | `grade` 平场 | 挖一格 → 一层平面被削平（仅 Lv1~3） |

操作：**按住技能键**再破坏方块（不按键不应触发）。

## 2. 右键族（USE）—— 触发点：右键物品 / 对方块使用物品

| 工具 | 技能 | 期望现象 |
|---|---|---|
| 锄头 | `hoe` 耕作 | 按住技能键对泥土/草方块右键 → 一片地同时被耕作 |

> ⚠ 这一组专门验证我在换核中途**误删又恢复**的 `UseItemHandler`。若耕作完全无反应，就是它的问题。

## 3. 受击族（HIT）—— 触发点：玩家直接造成伤害

| 武器 | 技能 | 期望现象 |
| --- | --- | --- |
| 剑 | `skin` 剥取 | 按住技能键攻击生物 → 除常规掉落外多掉一份（按等级概率） |
| 剑 | `plunder` 夺取 | 按住技能键攻击生物 → 吸血 / 夺取目标手中装备（按等级配置） |

> ⚠ 这一组专门验证我在换核中途**误删又恢复**的 `HurtLivingEntityHandler`。完全无反应就是它的问题。

## 4. 弓（USE，独立触发）—— 触发点：拉弓松手射击并命中

| 武器 | 技能 | 期望现象 |
|---|---|---|
| 翠玉之弓 | `bow_curse` 凋零诅咒 | 命中生物 → 目标获得凋零 + 缓慢，且生成药水云 |
| 翠玉之弓 | `bow_disarm` 缴械风暴 | 命中生物 → 范围内生物被缴械（可入背包），怪物可能被扒装备 |

- 注意：弓技能在**松手射击**时释放（不是拉弓瞬间）；命中时生效。
- 另：**普通箭也有 50% 概率的基础效果**（20% 凋零 / 20% 缓慢 / 10% 转化紊乱+缴械主手）——这是既有设计，不算技能。

## 6. 回报格式（有问题时）

请告诉我三件事，我按触发链（触发点 → 按键槽位 → 上下文工厂 → 技能实现）逐段定位：

1. **哪一组**（1 挖掘 / 2 右键 / 3 受击 / 4 弓）
2. **现象**：完全无反应？有效果但不扣能？扣能但无效果？报错崩溃（附 `run/logs/latest.log` 或 `run/crash-reports/*`）？
3. **环境**：单人存档 / 专用服务器；是否按住技能键
