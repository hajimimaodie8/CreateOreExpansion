# 共享经验：盔甲与材料集（给 COE / CEWS 的代理）

> **这份文档是外部经验输入，不是本仓库的历史记录。**
> 它来自另一个**真实项目** `bettergold`（NeoForge 1.21.1，模组 id `bettergold`，版本 1.4.0），那个项目刚刚
> 端到端做完「4 套金属的材料链 + 建材 + 五件器具 + 四件盔甲 + 盔甲纹饰 + 自定义 buff + 创造页分区横幅」，
> 并且每一条结论都有对应的实机验证记录。写这份文档的人**不是**这两个项目的代理，只做了两件事：
> ① 读 `bettergold` 的实战记录与源码；② 读本仓库（`createoreexpansion`）的盔甲 / 工具 / 材料 / 效果源码
> 并逐条核对 1.21.1 + NeoForge 的反编译源码。

术语约定：本文里的**「源仓库」**= `bettergold`；**「本仓库」/「COE / CEWS」**= `createoreexpansion`
（`:coe` = mod id `createoreexpansion`，`:cews` = mod id `cews`，两者都是 NeoForge 21.1.228 / MC 1.21.1）。

## 一、这份文档解决什么问题

本仓库已经有一套**可用的**盔甲与工具（4 套盔甲 16 件 + 5 个 Tier × 5 件器具），但：

- 盔甲的**贴图、纹饰、附魔、猪灵中立**这些「不报错但会静默错」的地方，没有任何静态关卡能拦住；
- 器具的**最终伤害/攻速**是「属性修饰符 + Tier 加成」两步相加的结果，肉眼读代码很容易算错；
- 自定义效果（`MobEffect`）在 1.21.1 有两套写法，写错的那一套**编译通过、显示正确、但完全不作用到实体**；
- 数据驱动的材料链（原料 → 熔炼 → 锭、锭↔粒↔块、锻造升级模板）漏一个文件就是**静默无效**。

源仓库把这些坑全部踩过一遍，代价是「读了 JSON 就说修好了，结果玩家刷半天不掉东西」这种事故。
这份文档把它们整理成**动手前能查、动手后能验**的清单。

## 四、可复现的源码出处（本机路径，换版本后行号会漂移）

本文档所有 `【读源码】` 的行号来自下面三处，都可以用 PowerShell 直接复现：

```powershell
# 1) Minecraft 1.21.1 反编译 + NeoForge 21.1.228 补丁源码（纯 Java 源，行号最稳）
#    注意：文件名里的哈希随 Gradle 缓存变化，用通配符取
$mc = Get-ChildItem "$env:USERPROFILE\.gradle\caches\neoformruntime\intermediate_results\sourcesWithNeoForge_*_output.zip" | Select-Object -First 1

# 2) NeoForge 21.1.228 自身的补丁源码（IItemExtension / LevelChunk 事件 / Tags 等）
$nf = "$env:USERPROFILE\.gradle\caches\modules-2\files-2.1\net.neoforged\neoforge\21.1.228\a4a27943259526d33758169e138940cd5d713f0a\neoforge-21.1.228-sources.jar"

# 3) 原版客户端资源（标签 JSON / 图集定义 / 贴图像素）
$res = Get-ChildItem "$env:USERPROFILE\.gradle\caches\neoformruntime\intermediate_results\stripClient_*_resourcesOutput.jar" | Select-Object -First 1

# 读其中一个条目（例：把 ArmorMaterial.java 取到 %TEMP% 再看）
Add-Type -AssemblyName System.IO.Compression.FileSystem
$zip = [System.IO.Compression.ZipFile]::OpenRead($mc.FullName)
$e = $zip.Entries | Where-Object { $_.FullName -eq 'net/minecraft/world/item/ArmorMaterial.java' }
[System.IO.Compression.ZipFileExtensions]::ExtractToFile($e, "$env:TEMP\ArmorMaterial.java", $true)
$zip.Dispose()
```

> 关键版本事实：本仓库与源仓库的 `neo_version` **都是 21.1.228**，`minecraft_version` 都是 1.21.1
> （见两个仓库的 `gradle.properties`）。所以本机这一份反编译源码**就是**两个项目实际编译时用的那一份。

- 涉及的 API 事实全部核对过 1.21.1 + NeoForge 21.1.228 的最新可用反编译源码；但**行号会随版本漂移**，
